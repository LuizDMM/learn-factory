# Mission: Software factory (self-taught)

## Why

Luiz wants the engineering system of Matt Pocock's *Software Factories for Real Engineers* without buying the cohort until cash lands. He wants **both**: a lab factory that actually runs on a repo he owns, and concepts that transfer to real work later.

The cohort is pedagogy, a licensed sandbox, and office hours. It is not required to learn the system. The system is public: MIT skills, Sandcastle, the factory dictionary.

## Success looks like

- AFK-delegate a well-specified ticket on `playground/` and come back to a **draft PR he is willing to read**
- Use the workspace vocabulary (smart zone, harness, brakes, trigger, factory) without cargo-culting "Claude in GitHub Actions"
- `GLOSSARY.md` holds terms he can actually use — not a dump of Matt's dictionary unread

## Constraints

- **Cadence:** evenings / spare blocks. One lesson + one playground change. Not a second job. Lunch stays empty while this runs (`learn-craft` is paused).
- **Playground:** original tiny Udemy-like app — React Router + Vite + SQLite, pages, seed data, a DevUI-style user switcher. Same *shape* as Matt's lab. **Not** a copy of `ai-hero-dev/cohort-005-project` (ARR, students only).
- **Reference:** `mattpocock/sandcastle` (MIT) for factory / GHA patterns; public AI Hero dictionary, skills, and crash-course pages for vocabulary. Cohort README is a **map**, not a syllabus to `reset`.
- **Order:** crash-course concepts (arc 0) → brakes → factory last. AFK worker (Grok Build in Actions vs Hermes cron) is **not** locked until the factory arc.
- **Grey box, not dark factory.** No auto-merge. Luiz reviews.
- **Off-limits as the lab:** Visian prod, SpaceXAI. This repo never contains employer/client source.
- **This chat is the teacher**, not the factory. Babysitting tickets here is out of scope.

## Out of scope

- Cloning, `npm run reset`, or cherry-picking `live-run-through` / lesson commits from `cohort-005-project`
- Completing paid sandbox exercises without a seat
- Starting with Ralph loops
- Waiting on a `grok()` Sandcastle provider
