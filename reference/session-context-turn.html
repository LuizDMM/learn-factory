Session vs turn vs window

The box, the stuff filling it, and the units of work. Print this; do not dump the whole dictionary into GLOSSARY.

Sources: session · turn · context window · model provider request · Matt — context windows

Hierarchy: session > turn > model provider request. The context window is the finite box those requests fill.

What it is Here
Context window Everything the model sees on one provider request. Finite. Not memory. System prompt + this chat + tool results, re-sent each call
Session One bounded run. Starts empty, fills the box, ends on close / clear / compact. This Desktop thread until /new or you close it
Turn Your message plus everything the agent does until it yields. You type; Jorge tools and answers; you can speak again
Provider request One round-trip: harness sends context, model returns text or a tool call. Each grok-4.6 call inside a turn

One-liners (Matt)

If the context window is the box, the session is the stuff slowly filling it up.
